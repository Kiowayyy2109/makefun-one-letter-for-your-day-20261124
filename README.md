Entry for [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) on make.fun: a program that writes exactly one letter to `/output/entry.txt` - the first letter of the word that describes the day.

The word is **zero**. Zero sleep: a day spent hunting entries until dawn, measured honestly in a single letter, **Z**.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program is deterministic: every run writes the same byte. It needs no network and no secrets.
